这是模拟 Pages CMS 保存时生成的条目，用来验证整条链路是否通畅。

## 为什么要做这个测试

后台能打开、能显示表单，不代表**保存后站点一定能正确渲染**。中间要经过：

1. 后台把表单内容写成 Markdown + front matter
2. commit 到仓库的 `_diary/` 目录
3. GitHub Actions 触发 Jekyll 构建
4. Jekyll 发现新文档 → 生成 `/diary/<文件名>/` 页面
5. 列表页与归档页自动收录

任何一环出错，日记都不会出现。这条测试就是把这 5 步一次性跑通。

## 通过标准

- 这篇能出现在 `/diary/` 列表里
- 详情页可访问，标题、日期、标签、正文都正确
- 归档页里带「日记」徽章
